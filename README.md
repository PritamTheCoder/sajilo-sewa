# Sajilo Sewa

Sajilo Sewa (सजिलो सेवा) is a local service marketplace web application designed to seamlessly connect customers with verified local service providers for household and professional needs like plumbing, cleaning, and tutoring. By providing a trusted platform for discovery, scheduling, and provider vetting, it bridges the gap in the unorganized local service sector and simplifies the way everyday services are booked and managed.

Live Demo: https://sajilo-sewa-silk.vercel.app/
